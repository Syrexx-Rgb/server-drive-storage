Privacy policy

Updated: 30 October 2026.

Server Drive Storage is a personal integration operated by its account owner using rclone. It is used to read, download, upload and manage files in the owner's Google Drive, including private server backups and video files.

Google Drive access is used to list files and folders, transfer their contents, verify transfers, and remove expired backup copies according to the owner's retention settings. Access is granted only with the Google account owner's OAuth consent.

Files are stored in the owner's Google Drive and, where needed for transfers and recovery, on the owner's server or computer. OAuth credentials are stored in restricted configuration files. This public information site does not receive OAuth credentials or private file contents.

The integration does not sell Google user data or use it for advertising. File contents are transferred to Google Drive and the owner's devices as directed by the owner. This site and the storage services are subject to their respective hosting providers' operations and policies.

Access can be revoked in Google Account third-party connections. Revoking access does not automatically delete existing copies. The owner controls file deletion and backup retention.

This integration is intended for personal use by its owner and is not offered as a public storage service.
